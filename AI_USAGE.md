
# AI Usage Documentation

## AI Tools Used

ChatGPT was used as an AI assistance tool during the development of this project.

## How AI Was Used

AI assistance was used for:

- Understanding Flask application structure and routing.
- Writing and debugging Python Flask code.
- Creating HTML templates for the application's pages.
- Developing SQL queries for database operations.
- Implementing CRUD functionality for all four database tables.
- Developing the Job Match feature.
- Improving CSS styling and dashboard presentation.
- Troubleshooting errors during development.
- Creating project documentation.

## Developer Responsibilities

The developer reviewed, implemented, and tested the generated code.

AI-generated code was integrated into the project and adjusted when errors or compatibility issues occurred.

## Testing

The application was tested by running it locally and checking the functionality of its pages, database operations, and Job Match feature.
